## English

### Overview

This repository is dedicated to collecting **user feedback** for 7x24xN Workplace.  

We welcome suggestions, bug reports, feature requests, and general comments to help improve our products and services.

### How to Submit Feedback

1. Go to the **[Issues](../../issues)** tab.
2. Click **New Issue**.
3. Choose the appropriate template (if available) or create a blank issue.
4. Please include:
   - A clear title
   - Detailed description
   - Steps to reproduce (for bugs)
   - Screenshots or logs (if applicable)
5. Submit the issue.

### Thank You

Your feedback is extremely valuable to us. Thank you for helping us improve!

### 概述

本仓库专门用于收集针对7x24xN Workplace的**用户反馈**。

我们欢迎各种建议、问题反馈、功能需求和一般性意见，帮助我们不断改进产品与服务。

### 如何提交反馈

1. 进入 **[Issues](../../issues)** 页面。
2. 点击 **New Issue**（新建 Issue）。
3. 选择合适的模板（如有）或创建空白 Issue。
4. 请尽量包含以下内容：
   - 清晰的标题
   - 详细描述
   - 复现步骤（针对 Bug）
   - 截图或日志（如适用）
5. 提交 Issue。
