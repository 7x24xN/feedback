### Overview

This repository is dedicated to collecting **user feedback** for 7x24xN Workplace.  

We welcome suggestions, bug reports, feature requests, and general comments to help improve our products and services.

### How to Submit Feedback

1. Go to the **[Issues](../../issues)** tab.
2. Click **New Issue**.
3. Choose the appropriate template (if available) or create a blank issue.
4. Please include:
   - A clear title
   - Detailed description
   - Steps to reproduce (for bugs)
   - Screenshots or logs (if applicable)
5. Submit the issue.
